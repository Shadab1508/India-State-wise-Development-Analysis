# India State-Wise Development Analysis

## Project Overview

This project analyzes development disparities across Indian states using a Composite Development Index developed through a weighted scoring framework.

The objective is to evaluate and compare the development performance of Indian states using economic, educational, health, employment, and digital indicators.

The analysis was performed using Microsoft Excel and Power BI.

---

## Objective

- Compare development levels across Indian states.
- Create a Composite Development Index.
- Identify top-performing and low-performing states.
- Analyze relationships between development indicators.
- Generate policy recommendations for improvement.

---

## Indicators Used

| Indicator | Weight (%) |
|------------|------------|
| Per Capita Income | 20 |
| GSDP | 15 |
| Literacy Rate | 15 |
| Life Expectancy | 15 |
| Unemployment Rate | 15 |
| Female Labour Force Participation | 10 |
| Internet Penetration | 10 |

---

## Methodology

1. Data Collection
2. Min-Max Normalization
3. Reverse Normalization for Unemployment
4. Weight Assignment
5. Composite Development Score Calculation
6. State Ranking

---

## Dashboard Pages

### Page 1 – Executive Summary
Provides KPI cards, state rankings, and top/bottom performers.

### Page 2 – Development Drivers & State Scorecard
Analyzes relationships between indicators and development performance.

### Page 3 – Regional Development Analysis
Compares states through ranking charts, treemaps, and ribbon charts.

### Page 4 – Policy Recommendations
Provides recommendations for improving development outcomes in lower-performing states.

---

## Key Findings

- Tamil Nadu emerged as the highest-performing state.
- Bihar recorded the lowest Development Score.
- Maharashtra and Kerala ranked among the strongest performers.
- Higher income levels generally corresponded with stronger development outcomes.
- Balanced performance across multiple indicators leads to higher development scores.
